This small verification packet records the Python interpreter and selected standard-library identities on an official Ubuntu 22.04 runner. Its output is an **unapproved fingerprint observation**. It does not execute either synthetic guard mode, install the Lean runtime, restore research objects, or establish a proof result.

The single job is bounded to 10 minutes. Its controller has one original 180-second budget and an external 210-second watchdog; the observation child has at most 120 seconds, one CPU, and 1 GiB address-space and target-tree RSS limits. The separately bounded parent has its own 1 GiB address-space allowance, so these are not a combined 1 GiB limit. The child has no network or workflow token. Its system and code mounts are read-only; it has a writable private /tmp tmpfs and no writable evidence mount. The fixed observer contains no temporary-file creation path. The parent launch environment contains exactly LANG, LC_ALL and TZ. Bubblewrap adds PWD for its fixed --chdir directory; the observer requires exactly those four child environment keys and requires PWD to equal its own source directory. Accepted stdout and stderr total at most 256 KiB; physical capture reserves remain larger and explicit.

Only seven fixed evidence paths can be uploaded. A successful upload marker binds the artifact ID/digest, run/attempt/commit, contract, and completion hash. Partial evidence remains incomplete. Terminal job success and independent reconciliation of the exact observation are required before any later profile decision. A separate reviewed exact-profile binding and fresh guard-mode run are still required.
