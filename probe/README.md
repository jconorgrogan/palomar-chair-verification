# Inactive standalone Lean heap-option probe

This probe acquires only the same exact official Lean 4.35.0-rc2 archive and installs it with the unchanged retained installer. It runs the existing sandbox preflight and then one small Lean.Shell program with -j1 -M5120 --run. No project archive is extracted, no dependency/cache or predecessor artifact is acquired, and no H5 module is recompiled. The published project contract, seven CI helpers, theorem/auditor sources, seven historical producers and failed runs remain untouched.

The program reads the compiled default and only the compiled max_memory override through Lean.Internal.getDefaultMaxMemory and getOptionOverrides. Options.find? distinguishes absent, natural value and other type. It neither sets nor resets any threshold, imports any project module, nor prints other override values. Exact accessor source files match the retained runtime inventory. This standalone observation cannot directly read the runtime's current global threshold or prove what occurred in the failed auditor process.

The only accepted stdout is one ASCII line: LEAN_HEAP_PROBE_V1 default_mib=<unsigned decimal> override=absent|nat:<unsigned decimal>|other, followed by one newline. Each integer is bounded to uint64, the whole line to 160 bytes, and stderr must be empty. Presence is reported independently of value, preserving an explicit zero override. Unexpected types are reported as other without exposing their contents. No proof result is inferred.

The controller has a 1,800-second aggregate host deadline and the workflow a 35-minute outer limit. The public release download retains its 900-second/595,391,556-byte bound, exact SHA and canonical inventory. The sandbox preflight has 30 seconds and 12 GiB AS. The one probe has 600 seconds and 24 GiB per-process AS. Both retain the 8 GiB sampled tree RSS, 512 MiB created-file, 1 MiB per-command log and existing process-tree cleanup rules. No increased heap value is used. The safe native environment contains no token or inherited credential.

Run: python3 -I -B probe/heap_probe.py --contract-sha256 C --work WORK. Always-run collection uses the same command with --collect, then uploads only WORK/upload/**. It invokes the unchanged bounded collector with its existing 128 MiB envelope and regular-file checks. Its legacy conditional-C label is non-applicable inherited collector metadata, explicitly explained in probe-collection-scope.json. PROBE_OBSERVED and proof_certified=false are the only diagnostic completion claim; replay_acceptance_evidence_complete must remain false. Native stdout/stderr live outside the collector log tree. Scalar native receipts are recorded before any capture read. Only safety-accepted, bounded regular single-link captures with retained descriptor and post-close named-path identity are hashed, registered and admitted to the unchanged collector.
